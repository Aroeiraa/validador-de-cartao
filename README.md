# Validador de Cartão de Crédito

Este é um projeto simples para validar números de cartão de crédito, CVV e data de validade. Ele utiliza HTML, CSS e JavaScript para criar uma interface intuitiva e funcional.

## Funcionalidades

- **Validação de Número do Cartão**: Verifica se o número do cartão é válido.
- **Validação de CVV**: Confirma se o CVV inserido está no formato correto.
- **Validação de Data de Validade**: Garante que a data de validade está no formato MM/AA e não está expirada.

## Estrutura do Projeto

- `index.html`: Arquivo principal contendo a estrutura da interface.
- `style.css`: Arquivo de estilos para personalizar a aparência do projeto.
- `index.js`: Arquivo JavaScript responsável pela lógica de validação.
